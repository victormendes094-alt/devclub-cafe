## ✨ Funcionalidades

- **Layout responsivo:** funciona no desktop, no tablet e no celular, com menu hambúrguer em telas pequenas
- **Carrinho de compras:** adicionar e remover itens, alterar quantidades e ver o total em tempo real
- **Carrinho salvo:** os itens continuam lá ao recarregar a página (`localStorage`)
- **Busca no menu:** filtra os produtos enquanto você digita, ignorando acentos ("medio" encontra "Médio")
- **Acessibilidade:** HTML semântico, navegação por teclado (Esc fecha os painéis), `aria-label` nos botões de ícone e respeito à preferência de "reduzir animações"
- **Ícones em SVG:** sem dependência de bibliotecas externas

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, variáveis CSS e media queries)
- JavaScript (DOM, eventos e localStorage)

## 📚 O que aprendi

- Estruturar uma página com tags semânticas (`header`, `main`, `section`, `footer`)
- Criar layouts responsivos com Grid `auto-fit` e media queries
- Manipular o DOM e guardar estado com JavaScript sem frameworks
- Cuidar de acessibilidade: foco visível, textos alternativos e leitores de tela
